System overview

Tổng quan hệ thống

Hệ thống Desk Robot dùng ESP32 làm bộ xử lý trung tâm, thu thập dữ liệu từ cảm biến AHT20, BMP280 và BH1750 để đo nhiệt độ, độ ẩm, áp suất và ánh sáng. Dữ liệu được gửi lên Firebase Realtime Database và hiển thị trên Web Dashboard. Người dùng có thể theo dõi dữ liệu realtime, xem biểu đồ, điều khiển robot và nhận phân tích thông minh từ AI/MCP.

IoT architecture

Kiến trúc IoT

01
Lớp cảm biến

AHT20, BMP280 và BH1750 thu thập dữ liệu môi trường.

02
Lớp xử lý

ESP32 đọc, kiểm tra, chuẩn hóa và đóng gói dữ liệu.

03
Lớp truyền thông

Wi-Fi và HTTP REST truyền dữ liệu lên nền tảng cloud.

04
Lớp cloud

Firebase Realtime Database đồng bộ dữ liệu hai chiều.

05
Lớp ứng dụng

Web Dashboard hiển thị dữ liệu, biểu đồ và lệnh điều khiển.

06
Lớp thông minh

AI Agent / MCP phân tích dữ liệu và đưa ra gợi ý.

Main features

Chức năng chính

01Giám sát môi trường

Nhiệt độ, độ ẩm, ánh sáng, áp suất theo thời gian thực.

02Dashboard realtime

Hiển thị số liệu, trạng thái robot và cập nhật từ Firebase.

03Điều khiển robot

Chào, vẫy tay, quay đầu, nhìn thẳng và dừng.

04Đăng nhập OTP

Xác minh email bằng OTP qua EmailJS trước khi vào hệ thống.

05Phân quyền Robot ID

Admin cấp/thu hồi quyền truy cập robot cho từng user.

06Biểu đồ & lịch sử

Xem dữ liệu theo ngày và xuất CSV/JSON phục vụ báo cáo.

07AI/MCP Insight

Phân tích môi trường và hỗ trợ ChatBox Python.
